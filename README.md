# RoomMate · Спальня

[Открыть первую тестовую сборку](https://sanatsergej-cmyk.github.io/roommate-bedroom-demo/)

RoomMate показывает спальню 340 × 410 см. На плане детали видны сверху. Во вкладке «3D» комнату можно вращать и переключать на вид сверху. В обоих режимах доступны одни и те же настройки.

- **Мебель.** Четыре позиции для кровати, кресла, телевизора, света и каждой из двух тумб. У товаров есть коды, размеры и ссылки на карточки.
- **Отделка.** Четыре напольных покрытия и варианты стен, ковра, двери и оконной рамы. Выбор отделки сохраняется в браузере.
- **Комплектация.** Демо показывает доступную ширину для правой тумбы, учитывает состав кровати и повторяющиеся артикулы, считает известные цены и выгружает CSV после согласования.

Это тест на одной фиксированной планировке. Изображения и 3D-модели передают общий вид. Размеры предметов взяты из карточек. Цены и наличие уточняются у продавцов.

## Локальный запуск

```sh
python3 -m http.server 8000
```

Откройте локальный адрес `http://localhost:8000/`. В папке уже лежит собранный 3D-исполнитель. Чтобы пересобрать его после изменения исходника, выполните `npm ci` и `npm run build`.

3D-сцена использует Three.js. [Лицензия MIT](roommate-three-license.txt)
